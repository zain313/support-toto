# البيت العراقي للتخليص الكمركي — iqbait.com

موقع مكتب تخليص كمركي في منفذ زرباطية الحدودي (واسط، العراق) مقابل منفذ مهران الإيراني، بأربع لغات: العربية، الإنجليزية، الفارسية، الصينية.

Website of a customs clearance office at the Zurbatiyah border crossing (Wasit, Iraq), opposite Iran's Mehran crossing — Arabic, English, Persian and Chinese.

## Editing

Pages are generated from `_src/`. Edit the texts in `_src/i18n/*.json` (or the templates in `_src/templates/`), then run:

```sh
node _src/build.mjs
```

and commit everything. See `CLAUDE.md` for details.
